A schematic is a self-contained build specification — every requirement, parameter, dependency, phase, and acceptance test for a capability — implementable by any LLM, team, or org, in any runtime, without ever contacting the author. The spec is the only coordination mechanism.

What is an agentic schematic?

In Daniel Suarez's Daemon, the Darknet spreads through shared schematics: publish the spec, and independent teams build the network — no central authority, no coordination. Agentic schematics apply the same pattern to software capabilities. The schematic replaces the author: no meetings, no shared history, no access to the original conversation.

Self-contained

Every requirement, parameter, dependency, phase, and test lives inside the package. No "see the original repo", no "ask the author".

Vendor-agnostic

Plain Markdown and portable shell. Any LLM with a shell and a text editor can execute it.

Idempotent

Every phase is safe to re-run. Verification gives the same verdict every time.

How it works

01

Author or reverse-engineer

Write a schematic from an idea, or distill one from a working implementation.

02

Publish once

One Markdown file is the entire coordination. Push it to a repo, paste it into a session, hand it to a stranger.

03

Anyone builds, independently

Any LLM in any runtime follows the phases, discovers local parameters, and proves the result against the acceptance tests.

SCHEMATIC.md (skeleton)
name: my-schematic
version: 0.1.0
status: draft

## Requirements    → R-1, R-2, ... (testable)
## Dependencies    → D-1, D-2, ... (with failure behavior)
## Parameters      → P-1, P-2, ... (with discovery methods)
## Modules         → one contract per module
## Implementation  → idempotent phases with verification
## Acceptance      → A-1, A-2, ... (one per requirement)

Hard questions, answered plainly

Won't better models make this obsolete?

Parts of it, and we trim those parts as they do. What ages well: verification literals, parameter discovery, explicit failure behavior. The format is a living spec precisely so the dumb-builder scaffolding can be cut as builders get smarter.

Who has actually built anything from one?

The first schematic was reverse-engineered from a production fleet and re-implemented from the spec; the next milestone is an independent build by someone with no connection to the author, logged publicly.
